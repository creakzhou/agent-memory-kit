## Context

This note exists so a new session does not start by interviewing me again.

## Body

- Wants the conclusion in the first sentence, reasoning after.
- Prefers a table over three paragraphs when comparing options.
- Will say "just do it" when the decision is reversible. Will want options when
  it is not.
- Reviews code by reading the diff, not the summary.

## Decision / conclusion

When unsure whether a detail matters, say the uncertainty out loud instead of
quietly making a choice. Silent judgement calls are the main source of rework.
