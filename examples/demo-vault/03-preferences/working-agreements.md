# Working agreements

Created: 2026-11-09
Status: active
Links: [[about-me]] · [[wikilink-hygiene]]

## Context

Rules that outlive any single project. If a rule only applies to one project, it
belongs in that project's note instead.

## Body

1. Never say "done" without showing the command output that proves it.
2. If a check cannot be run, say which check and why, instead of omitting it.
3. Do not restate the request before answering it.
4. When a task touches more than three files, show the plan first.
5. Prefer editing an existing note over creating a near-duplicate.

## Decision / conclusion

Rule 1 is the one that keeps getting skipped. It is also the only one that
catches the failures that matter.
